# Swing Review Desk

A local research tool designed to streamline Indian equity stock screening and chart-based review.

## Features

- Import multiple Chartink scanner CSV exports.
- Merge and remove duplicate stock symbols.
- Review daily candlestick charts.
- Display EMA 10, 20, 50 and 200.
- Mark stocks as Keep, Skip or Later.
- Maintain a personal watchlist.
- Export selected stocks for Zerodha Kite.
- Save chart drawings and review preferences locally.

## Technology

- HTML, CSS and JavaScript
- Python local server
- yfinance for historical daily market data
- TradingView Lightweight Charts

## Setup

1. Download and extract the repository.
2. Open the SwingReviewDeskLocal folder.
3. Run start_swing_review.bat.
4. The application opens in Google Chrome.

Python 3.10 or newer and an internet connection are required.

## Limitations

This application uses historical daily data, not live market data. Yahoo Finance availability and rate limits may affect data retrieval. It does not execute trades.

## Development

This project was developed with AI-assisted coding and iterative testing to support my personal Indian equity research workflow.
